# Event Mobility ETL API

A lightweight Python API that runs ETL pipelines for event mobility data. This repository provides endpoints and tooling to trigger ETL jobs, monitor job status, and expose metrics for observability.

# Features
REST API to trigger and manage ETL jobs
Configurable data sources and sinks
Docker-friendly; can be run locally or in containers
Health checks and basic metrics for monitoring
Simple start / stop / status operations for ETL pipelines
